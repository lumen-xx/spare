# Spare 0.5.3

- **Permissions only System Settings can remove are marked as such.** Tools known only by their file path that apply to every account sit in a part of macOS's permission database that System Integrity Protection guards, even from an administrator. Spare no longer asks for your password to try; these rows say "removed only in System Settings", and Open Settings… goes straight to the right page, such as Full Disk Access or Input Monitoring.
