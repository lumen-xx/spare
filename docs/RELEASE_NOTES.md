# Spare 0.3.0

Closer to a new Mac, without wiping it. Every topic now has its own page in the sidebar.

- **Leftovers** is its own page and now includes /Library, which every account shares: folders of products that are gone (VMware, Little Snitch, Karabiner, Logitech and the like), their settings, and folders of shortcuts to removed apps. Anything of macOS's, or of a company whose software is still installed, is left alone.
- **Toolchains**: Rust toolchains and rustup, Node versions (nvm, fnm, Volta), Python and Ruby versions, conda, SDKs, and Xcode's Command Line Tools.
- **Command-Line Tools**: commands in /usr/local no package manager tracks, with broken links left by removed apps marked.
- **System Additions**, each its own page: System Extensions, Drivers, Plug-ins, Fonts, Input Methods, Installer Packages, and **Search Paths** (where Terminal looks for commands; entries for removed apps are flagged).
- **System Changes**: hidden **Accounts** installers created (deleted after one password prompt), added **Printers**, **VPN** configurations, configuration **Profiles**, and **Privacy** permissions given to apps, with apps that are gone marked and decisions resettable.
- **Home Folder**: **Hidden Items** in your home folder, named by the tool that owns them, with keys marked and leftovers of removed tools flagged; and the **Shared Folder** every account can use.
- **Snapshots** and **macOS Downloads** are separate pages.
- macOS asks for your password less often: one request covers everything you selected, and the same session doesn't ask again for five minutes.
