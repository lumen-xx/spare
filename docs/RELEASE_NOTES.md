# Spare 0.4.2

- **Privacy permissions of removed apps can be deleted.** macOS's own tool refuses apps that are no longer installed, so before, nothing was removed even though Spare said it was. Delete now removes them (one administrator password for those that apply to every account), then looks again and says exactly what's gone.
- **Look Again reads everything again**: every page you've opened, the sizes Spare had measured, the disk and the Trash.
- The message at the bottom no longer appears again when you switch pages.
- The highlight under the pointer sits evenly inside its card, and the Apps page's title bar looks the same all the way across.
