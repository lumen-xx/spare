# Spare 0.1.0

The first preview: an honest way to get disk space back.

- **Cleanup** finds Xcode build data, device support files, node_modules and other build folders in projects you haven't touched for a month, package manager caches, app caches, logs and crash reports. Each one says what it is and what happens once it's gone. Only things that come back by themselves are selected.
- **Your Call** lists old downloads, iPhone backups, Xcode archives and AI models, and never selects them for you.
- **Space** shows which folders take the most room, and lets you open them as deep as you like.
- **Apps** uninstalls an app together with the files it keeps in your Library, and finds leftovers of apps you already removed.
- **Background Items** lists everything that starts on its own, says which app it belongs to, flags ones whose program is gone, and removes them.
- **History** lists everything Spare moved to the Trash, and puts it back with one click.

Spare never deletes anything itself. It has no background process, no menu bar icon and no scare warnings, and it never sends anything anywhere.
